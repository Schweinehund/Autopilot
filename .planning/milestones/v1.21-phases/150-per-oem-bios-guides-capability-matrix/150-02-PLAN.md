## The Dell 241-character quote — shipping-format decision, made here

This decision is made in the plan, not left to the executor, because getting it wrong is
fabrication-adjacent.

**The problem.** Success Criterion 3 and BIOS-07 mandate Dell's no-customer-data statement be quoted
against HP's cloud-vault statement. `150-RESEARCH.md` Pitfall 1 records that the milestone research
shipped it truncated to **166 characters**, and that the complete, accurate sentence re-fetched from
Dell KB 000356434 on 2026-08-25 is **241 characters** — the omitted clause states the data-flow
mechanism, so the truncation changes what the sentence claims. 241 crosses C17's 200-character
blockquote cap.

**The decision: ship the complete 241-character sentence as a single bare `>` blockquote in this
file, unsplit and unabbreviated.**

**The ground, measured, not assumed.** `[MEASURED]` `grep -rln "doc_id" docs/operations/firmware-bios/`
returns zero — every file in this directory is unenrolled. `[MEASURED]`
`scripts/validation/c17-eee-contract.mjs:5-6` enrolls on `doc_id` plus a `docs/` path and nothing else,
and its assertion 12 at lines 389-408 only walks enrolled files. **C17's 200-character cap therefore
does not bind this file at all**, which is exactly what D-10 established when it measured five other
load-bearing strings over the cap and ruled they ship in the guides on that ground. The 241-character
Dell statement is the sixth string on that list, per the D-10 research addendum.

**Why not the two alternatives `150-RESEARCH.md` offered.** Option (a), first-sentence-only plus an
unquoted claim, is a truncation-to-fit against a cap that does not apply — the precise anti-pattern
`150-RESEARCH.md` names, applied to a vendor's own security-relevant statement. Option (b), a
structural split into two blockquotes separated by a blank line, exists to escape a cap that does not
apply here, and it visually fractures one sentence for no benefit.

**Where the cap does apply, and how that is handled.** The cap binds the matrix (`RE-226`, enrolled)
and `docs/_glossary.md`. Neither carries this quote: matrix cells are literal strings, never quotes
(D-19), and the glossary terms are definitions. So the 241-character sentence never enters an enrolled
file, and C17 stays at 0 violations. Plan 04 asserts that.

**The quote, exactly:**

`Dell does not collect or retain any customer data from Microsoft Intune. The data remains in the Microsoft tenant but is supplemented with Dell-specific capabilities which are transacted with Microsoft infrastructure through Graph API calls.`

Source: Dell KB 000356434, `how-to-connect-dell-management-portal-to-microsoft-intune`, Version 2,
Last Modified 2026-05-23, re-fetched 2026-08-25. The source carries no emphasis markup; do not add
any. The clause the milestone research dropped begins `which are transacted` — verify it is present
before shipping.
