<threat_model>
## Trust Boundaries

This plan adds one Node pipeline script and hand-edits one Markdown registry file. It introduces NO
runtime, network, authentication, session, user-input, or cryptographic surface. The pipeline runs
locally on trusted in-repo content. The only integrity concerns are (a) not injecting doc_id into a
Mermaid-bearing file (which would trip the C17 #1 gate) and (b) the pipeline resolving doc_id ONLY from
the hand-authored registry, failing closed if a path is absent.

| Boundary | Description |
|----------|-------------|
| hand-authored RE-index.md rows → pipeline buildDocIdMap() | The join-on-Path source of truth; a missing/mistyped path fails closed (DOC-ID-UNRESOLVED), never silently mis-injects |
| fork --all enumeration → doc corpus writes | The 9 Mermaid-bearing paths must never be enumerated/injected (would enroll a Mermaid file → C17 #1 hard-fail) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-121-01 | Tampering (of enforcement) | retrofit-structural.mjs writing doc_id into a Mermaid file | mitigate | MERMAID_DEFERRED_PATHS hard-excludes the 9 files (fail-closed on explicit path; filtered from --all); verified by --self-test refusal sub-test |
| T-121-02 | Tampering | buildDocIdMap resolving a wrong/absent path | mitigate | Fail-closed DOC-ID-UNRESOLVED guard carried verbatim; --dry-run --all proves 0 ERRORS before any write |
| T-121-03 | Repudiation | registry Doc Type column drift (not machine-checked, D-05) | accept-with-verify | Column hand-authored per the explicit Reference/Guide assignments in the action; Plan 07 asserts final registry state |
| T-121-SC | Tampering | package installs | n/a | No npm/pip/cargo installs; the fork uses Node built-ins only (matches scripts/pipeline/ convention) |

Spoofing / Information-Disclosure / Denial-of-Service / Elevation-of-Privilege: no applicable new
surface — this is a pipeline-script fork plus a registry-table edit with no runtime execution path
reaching untrusted input.
