<objective>
Review, promote, register. In that order, in three commits, with the ordering the phase's own
amendment authorizes.

Purpose: this is where RE-237 stops being an imported draft and becomes a registered, publish-gated,
navigable Device Recipe. Three mechanisms make the order non-negotiable and one of them was
misdiagnosed in the phase's own discussion draft. The bundle's divergence guard fail-closes when a
registry-Approved row's frontmatter still reads Draft, so registering first creates a window in which
no zip can be written and no detector anywhere would report it. The only value the registry Status
column takes in this corpus is Approved, so the row cannot be parked. And the review that RCP-04
exists to protect is human, because nothing mechanical distinguishes a reviewed promotion from an
unreviewed one.

Output: a signed-off review, a two-site flip commit, one atomic commit carrying the registry row, the
three nav sites, the regenerated filename map and both canary bumps, and a closed origin seed.
</objective>
