<objective>
Fix the two tools this phase depends on downstream, then close the em-dash class corpus-wide with the
unmodified sweep and prove the close did not rewrite a protected string.

The packet emitter's context window collapses to the top of the file when a changed hunk has no
following anchor, which would hand the judge in plan 158-04 the wrong region. The verifier skill
documents two invocations that do not run and one expectation that is false by construction. Both are
fixed here, each in its own commit with no corpus path, because a tool commit that also touches the
corpus cannot be attributed later.

The sweep then closes the em-dash class across the whole corpus rather than across this milestone's own
edited subset, and its correctness is proven by three independent guards rather than by the
substitution table's own lookarounds, which fail closed on a wrapped line and therefore cannot evidence
themselves.

Ordering: D-69 constraint 2 puts the tool edits in their own commits; D-69 constraint 3 puts the judge
after the sweep, so both must land before plan 158-04; the hand remediation in plan 158-02 has already
landed, so the sweep cannot rewrite a line the remediation was about to change.

Purpose: give plan 158-04 a correct packet emitter and give plans 158-05 and 158-06 a corpus whose last
mechanical change is attributable.
Output: two corrected tools, one date-stamped exclusion record, and the closed em-dash class with its
15-file target list recorded.
</objective>
