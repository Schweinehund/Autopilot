Put the push to the owner as a blocking decision with every pre-flight measured at the checkpoint, and
on proceed publish the default branch with exactly one command.

Purpose: this is the one-way door. There is no un-push, and the push publishes the entire unpushed set
including populations imported from outside this workflow. A predecessor milestone sat blocked for
weeks at exactly this shape, which is why the defer branch exists — so the phase halts cleanly rather
than half-executing.

Output: a recorded owner selection, and on proceed a published default branch whose head is recorded as
the provisional shared commit, with the explicit note that the next plan supersedes it.
</objective>
