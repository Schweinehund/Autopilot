**Status:** OPEN — routing document, not a milestone-close artifact.

**Authoring rationale.** Unlike the predecessor `vX.Y-DEFERRED-CLEANUP.md` files (each authored at its
milestone's close-gate), this document is authored **mid-milestone**, at Phase 142's Wave 1, because
`142-CONTEXT.md`'s `<deferred>` block names twelve items discovered during Phase 142's own
`/grill-me` + `/adversarial-review` scoping that this phase's requirements (RED-04/05/06/07, NEST-01)
do not cover. Per Phase 141's own precedent, "an unrouted deferral is itself the defect" — this file
gives every one of the twelve items a named destination now, rather than letting them evaporate
between this phase's SUMMARY and the eventual v1.20 close-gate's own deferred-cleanup authoring.

**Placement:** Milestone-level (`.planning/milestones/`), not phase-dir-level — chosen for the same
reason `v1.20-GOV-02-LEDGER.md` is: it avoids any `resolveArchivedPhasePath(..., ['v1.20-phases'])`
call site and means no later phase in this milestone mutates a completed phase's own artifact.
Verified safe at plan time: every validator reference to a deferred-cleanup file names a specific
predecessor file by path (e.g. `v1.19-DEFERRED-CLEANUP.md:252`'s non-collapse rule, cited by
`REQUIREMENTS.md:69`); none globs the `.planning/milestones/` directory or counts files in it, so
adding this file mid-milestone introduces no new validator surface.

**Relationship to the eventual v1.20 close-gate deferred-cleanup document.** This file is NOT a
substitute for the `v1.20-DEFERRED-CLEANUP.md` (or `v1.21-DEFERRED-CLEANUP.md`-named successor) that
Phase 144's close-gate will author following the standard per-milestone convention — that document
will additionally carry whatever new items surface in Phases 143-144 and will supersede this one's
routing where the two overlap (items 7 and 8 below, both routed to Phase 144 CONTEXT, are expected to
be consumed and closed before that document is authored). This file exists so the twelve items are
not silently lost in the interval between Phase 142 and that eventual close-gate document.
