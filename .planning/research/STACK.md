**Confidence:** MEDIUM-HIGH (every load-bearing claim below is [SOURCED] to a fetched Microsoft Learn page with its visible `ms.date`, or to a fetched GitHub file at a resolvable commit; two items are explicitly [UNVERIFIED] and must not be asserted as fact by the new docs)

## Stack Patterns by Variant

**If the kiosk fleet standardizes on IoT Enterprise (LTSC) hardware (Pillar D outcome A):**
- Shell Launcher becomes available immediately (edition gate satisfied), no MAK activation step needed for that gate specifically.
- The OEM-cleanup remediation class (Pillar B's HP bloat inventory) may still be needed if the hardware ships a Long-Term Servicing Channel image with its own OEM utilities — LTSC does not, by itself, guarantee a clean image.

**If the kiosk fleet stays on retail/DPK Enterprise activated via MAK (Pillar D outcome B):**
- Multi-app Assigned Access (the mechanism RE-237 already ships) remains necessary until MAK activation is confirmed per-device; Shell Launcher only "returns" (per the milestone goal) once the fleet's activation state is verified, not merely once the edition is Enterprise.
- The OEM-cleanup remediation class (Kiosk Baseline, drift remediations) stays in the corpus regardless — it is a factory-image problem, orthogonal to the licensing decision.

**If AVD host-pool Entra SSO (Pillar C) is adopted for this device class:**
- The Credential Guard/CredSSP failure mode (Pillar B reference row) becomes largely moot for the AVD-session RDP path specifically, since SSO replaces the saved-credential/CredSSP path with an Entra ID token — but Credential Guard still blocks CredSSP for any *other* delegation this device performs (e.g., an admin RDP-ing to the physical kiosk itself, which is a different hop than the AVD session-host connection).
- A Kerberos server object becomes a hard prerequisite only if session hosts are Entra-hybrid-joined, or Entra-joined into an environment that also has on-prem AD domain controllers — pure Entra-joined-only environments with no on-prem AD do not need one per the fetched page.
