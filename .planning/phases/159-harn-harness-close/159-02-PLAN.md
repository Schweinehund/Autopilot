## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| milestone tag to git command line | The tag selects a SHA that is interpolated into git subprocess arguments by the shared readers. |
| git object store to validator memory | Frozen blobs are read from history and treated as authoritative corpus content by every consumer of the pin. |
| the pinned prefix to the full object name | An 8-character prefix stands in for a 40-character object name; ambiguity or a wrong prefix silently redirects every downstream read. |
