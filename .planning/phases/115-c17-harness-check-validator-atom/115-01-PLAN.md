| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-115-01 | Denial of Service | assertion regexes in `checkFile` | mitigate | Use anchored, linear regexes; avoid nested/ambiguous quantifiers. The frontmatter regex `/^---\n([\s\S]*?)\n---/m` is lazy and bounded; structural assertions scan `bodyLines` line-by-line rather than backtracking over whole-file input — prevents catastrophic backtracking (ReDoS) on adversarial Markdown. |

| T-115-03 | Denial of Service | `readFileSync` full-file read | accept | Repo docs are small (<1MB); build-time local tool with no untrusted network input. Streaming would add complexity with no realistic payoff. |
| T-115-SC | Tampering | npm/pip/cargo installs | mitigate | Zero packages installed — node builtins only (D-04). No install task exists in this plan; the node-builtins-only invariant is grep-asserted in Task 2's verify. No `[ASSUMED]`/`[SUS]`/`[SLOP]` packages. |
