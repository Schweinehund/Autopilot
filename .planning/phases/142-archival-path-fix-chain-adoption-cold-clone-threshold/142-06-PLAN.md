  <action>
    Declare every variable BEFORE measuring, then measure. Record the declarations in the same place
    as the figures so no figure can later be read without them: node version, operating system,
    Defender real-time-protection state, machine-load attestation, tree identity for each figure,
    cache state for each figure, and whether the run was verbose. Tree identity is the variable that
    invalidated six of this phase's draft rows and it is not optional.

    **Warm denominator.** In the MAIN worktree, on the quiesced machine, run the apex an odd number
    of times, at least three, and record every individual wall-clock plus the tally each run
    reported. Take the median as the middle sorted value — using an odd n means the median is a
    single observed value, which is the tie-break rule the threshold requires rather than an averaged
    artifact. Record the quiescence attestation for this specific set of runs, since a warm median
    taken on a loaded machine makes the whole ratio meaningless.

    **Cold clone.** Make a FULL clone into a scratch directory outside the repository, with hardlinks
    disabled so the object store is genuinely copied. Attest the depth: the clone must carry no
    shallow marker and its commit count must equal the source tree's. Full depth is the ONLY
    admissible subject — a depth-1 clone makes the frozen-read helper fatal, which the milestone's
    first requirement already established. Confirm the clone's HEAD equals the source HEAD. Time the
    apex inside the clone an odd number of times, at least three, recording each wall-clock and each
    tally. Every run in the clone must report the adopted 95-check tally; a clone that reports 93 is
    a stale clone and the measurement is void.

    **Ratio.** Compute cold-clone median divided by warm median. Compare against the threshold of 8x
    or greater as a FAIL. State the result explicitly as a pass or a fail, not as a bare number.

    **The separate cold row.** Record first-invocation-of-session apex figures as their own row,
    distinct from the cold-clone row, expressed as a range across observations. That column is
    legitimate and the variance is high; never quote a single value for it.

    **Delete the manufactured contradiction.** Do not repeat the claim that the previously recorded
    cold Axis-1 figure cannot be cache-cold. That argument compared against the wrong warm baseline;
    the same session's own warm apex makes the ratio consistent with a cold clone, and a re-executed
    clone measured a ratio in the same low range with the second clone run slower than the first —
    so cache coldness is not even the dominant term. New-tree scanning is. Record that finding
    instead.

    **Name the CI cold clone that already gates.** Every CI job checks out at full depth onto a fresh
    runner — a genuine cold clone, on the runner class this project makes authoritative, already
    operative today. Record it, with Phase 141's fan-out as the precedent for reading per-job
    wall-clocks from job-level JSON.

    Remove the scratch clone when done and confirm zero orphan directories remain.
