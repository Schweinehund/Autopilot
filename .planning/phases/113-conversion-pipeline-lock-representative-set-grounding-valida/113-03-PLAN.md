| Boundary | Description |
|----------|-------------|
| Real corpus docs → working copies | canonical docs must remain unmodified; only copies are transformed |
| Converted .docx → guard verdict | the representative set is the last automated gate before the owner uploads to a live library |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-113-07 | Tampering | accidental modification of canonical docs/ originals | mitigate | Operate on copies under scripts/pipeline/test-fixtures/ only; acceptance asserts `git status --porcelain` reports no changes to the four canonical source files |
| T-113-04 | Spoofing (false-green) | guard verdict on the real set | mitigate (HIGH) | Every converted doc is run through the decompress-based guard; a single exit-1 halts the phase before the owner uploads a corrupting doc to the live library |

</threat_model>
