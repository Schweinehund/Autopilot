<objective>
Land SWEEP-09's thirteen reader sites: route `check-phase-61.mjs`'s inline `readAtV15CloseFor61`
through the shared frozen-read library so its throw propagates with a typed cause, and convert
the twelve `chicken-and-egg` call-site returns in `check-phase-68.mjs` (2) and
`check-phase-70.mjs` (10) from passing-but-skipped to failing. Then prove the change with the
`file://` shallow-clone negative harness Phase 139 built.

Purpose: SWEEP-09's remedy shape is removing the swallow, not hardening consumers (D-09). Per
D-08 the requirement's unit is reader SITES, not validators, and the claim that SWEEP-09's
intersection with RED-03 is empty is false — `check-phase-61.mjs`'s inline reader is exactly that
shape and `check-phase-61` is a RED-03 member, which is why Task 1 leads this plan. Both guarded
SHAs resolve today, so the bootstrap race these branches tolerate no longer exists — a null read
now means a real failure (unreachable SHA on a shallow clone, absent path, git missing from
PATH, a read timeout, or a corrupt pack), and reporting it as a pass is the exact vacuous-pass
class this milestone exists to delete.

Output: three edited validators, three new negative-harness assertions, three ledger rows.
