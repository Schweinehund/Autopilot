domain phase, and the per-vendor guides and matrix phase.

Purpose: three more chain members the apex requires. One of them is the plan's real hazard: the
application phase expressed most of its prohibitions against a phase-local base commit, which cannot
be transcribed into a permanent validator without making it red forever.

deliverables rather than on moving comparisons.
</objective>

<needle_doctrine>
Same doctrine as the first leaf plan, restated so this plan stands alone.

- **Durability, not scope.** Would this needle go red at the first content commit of the next
  milestone and stay red forever? If yes it is a bad needle however narrow. A corpus-wide negative is
  permitted when a ratified invariant makes the absence permanent — name the invariant in the check.
- **Derive at authoring time, never read at runtime.** Needles come from each phase's verification and
  summary documents, read now, baked in as literals.
- **Target the phase's own deliverables.** These phases shipped documentation.
- **Reconcile the arithmetic rule in writing** on every leaf.
- **State the gate-respawn decision in the header.** These leaves do not re-spawn corpus gates.
- **A null read is a failure**, never an empty string that satisfies a negative.
</needle_doctrine>

<non_transcribable>
**The application phase's emptiness assertions are NOT transcribable, and this is where that is
handled rather than discovered.**

That phase's verification document expresses most of its prohibitions as an emptiness assertion over a
change set measured against a phase-local base commit. Those base commits are unpinnable in a
permanent apex member: the assertion is true only at that phase's own close and goes red the moment
more commits land. Transcribing them produces a leaf that is red forever.

**Derive positive deliverable needles instead.** For every prohibition expressed that way, ask what
the prohibition was protecting and assert the protected state directly — the document that must still
carry its pin, the heading that must still exist, the cross-link that must still resolve. Record in
the summary, prohibition by prohibition, which positive needle replaced it and why the replacement
covers the same ground.
</non_transcribable>
