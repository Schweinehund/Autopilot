<objective>
Create the STATE-inspecting Stop-hook that fires the publish bundle automatically at milestone close, and activate it as a second sibling entry in `settings.local.json`. This is the core of HOOK-01: a new `.claude/hooks/publish-bundle-gate.cjs`, sibling to `jira-milestone-gate.cjs`, that on the milestone-complete transition — and ONLY when the versioned zip is absent — nudges the agent (via `block(reason)`) to run `node scripts/pipeline/build-publish-bundle.mjs --version=<milestone>` in the foreground. The design is fully locked by CONTEXT.md D-01..D-05 — do not re-open it; clone the proven Jira-hook skeleton.
Output: the committed `.cjs` hook (with an embedded `--self-test` dry-run harness satisfying SC#3) and the gitignored activation edit.
