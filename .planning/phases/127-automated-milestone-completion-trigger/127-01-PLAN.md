That flag must exist and be validated fail-closed before the hook can reference it. Reuse-don't-re-derive: the pipeline's conversion/guard/parity logic is already green (Phase 126) and MUST NOT be touched — only the version parameterization.
Output: A `--version=` argv flag + a pure `deriveZipName(version)` helper with anchored validation, plus self-test coverage proving the derivation and rejecting malformed input.
</objective>
