from a worktree blob comparison to the frozen-to-frozen form (D-19), adopting the

is flagged in neither ROADMAP.md nor REQUIREMENTS.md; it was surfaced only by the grep-before-edit
discipline this phase itself mandates, which makes it the GOV-02 failure class in miniature.

validators are apex chain members, and the current comparison reads the worktree, so it goes red
the instant a YAML is saved — before any commit. A single atomic commit does not close that window.

This one move discharges four otherwise-confirmed hazards (D-20): the working-tree atomicity
window; the silent weakening a re-baseline would cause; the `core.autocrlf` environment
dependence; and the forced second re-baseline a probe-step evidence design would have required.

Purpose: unblock SWEEP-01. Output: two apex chain validators converted, GOV-02 ledger rows.
