### The commit contract (D-80, owner-ruled 2026-08-25)

**TWO content commits, not five.**

1. **Commit A — the single content commit**, landed by **Plan 04**: the three guides, the matrix and
   the glossary edit, together, in one commit.
2. **Commit B — the overview commit**, landed by **Plan 05**: `00-overview.md` alone.

Therefore **plans 01 (task 2 onward), 02 and 03 author files and DO NOT COMMIT them.** They leave the
working tree dirty on purpose. Execution on this repository is sequential on the main tree
(`.planning/config.json` sets `use_worktrees:false`), so an uncommitted file authored by Plan 01 is
still present when Plan 04 runs. The only exception in Plan 01 is Task 1, which commits
`.planning/REQUIREMENTS.md` alone — a planning artifact, not corpus content, and outside D-80's scope.

The reason intermediate commits are forbidden: guide-to-guide cross-links, every guide-to-matrix link
and the overview's outbound links all dangle mid-sequence, in every possible ordering. The link
checker has **no baseline, allowlist, ratchet or expected-failure list**, so a partial landing is red
however it is ordered. D-80 chose to make the red state short and uncommitted rather than pretend an
ordering exists that avoids it.

### Evidence-line form (D-46, D-47)

One `**Source:**` line, at line start, immediately after the blockquote it evidences, covering **one
page only**. A blockquote may contain several contiguous quotes from that one page. Never let one
evidence line span two pages. Learn pages carry both dates — `(ms.date YYYY-MM-DD, updated
YYYY-MM-DD)`; vendor pages carry one — `(published YYYY-MM-DD)` or `(Version N, Last Modified
YYYY-MM-DD)`. Never invent the second date.

Blockquotes are the bare `>` form. `[MEASURED]` `grep -rn '^> \*"' docs/` returns 0 — the corpus has
never shipped an emphasis-wrapped blockquote.

runtime. The honest threat surface is what the published guide **tells a reader to do** with
credentials, secret custody and de-provisioning order — a reader acting on a wrong instruction is the
harm. ASVS level 1; block on `high`.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Vendor documentation → this corpus | Untrusted-for-currency input. A vendor KB is revised without notice; a quote correct at fetch time can be stale at read time. |
| This corpus → service-desk operator | The operator acts on the guide without re-deriving it. A wrong custody or RBAC claim becomes a wrong production action. |
| Intune tenant ↔ Dell Management Portal | A partner-portal consent grant that reads much lower-risk than it is. |
| Intune tenant → Microsoft Graph beta | A password-read path whose blast radius depends entirely on which role the reader is told to use. |
