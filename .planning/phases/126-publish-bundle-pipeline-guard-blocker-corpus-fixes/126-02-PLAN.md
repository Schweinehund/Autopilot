| orchestrator → pwsh / pandoc / node shell-outs | Command construction boundary; argv-array form prevents injection |
| orchestrator → dist/ zip write | Local build artifact; never committed, never network-exposed |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-126-02-01 | Tampering | convert.ps1 / guard / Compress-Archive shell-outs | mitigate | execFileSync(cmd,[argv]) exclusively; no exec()/Invoke-Expression/string-concatenated commands; verified by grep gate in Task 2 |
| T-126-02-02 | Tampering | source Path from registry | mitigate | Validate resolved Path stays under docs/ (reject `..` traversal) before reading/converting |
| T-126-02-03 | Tampering | output filename from filename-map.md | mitigate | Regenerate filename-map.md as a build step (never trust a stale/hand-edited copy); validate each output filename against slug charset `^[a-z0-9-]+\.docx$`; path.join into the staging dir, never raw string concat |
| T-126-02-04 | Information Disclosure | in-zip manifest | accept | Manifest excludes source-path and sha256 by design (D-03) — no RE-index mapping recreated, no false integrity signal; the CSV/MD are never indexed (connector indexes .docx only, §SC1) |
| T-126-02-05 | Spoofing/Elevation | partial bundle masquerading as complete | mitigate | Registry-parity assertion + always-full rebuild + atomic staging→promote; no zip on any failure (PUB-02/PUB-04) |
| T-126-02-SC | Tampering | package installs | accept | Zero new external packages; native pwsh Compress-Archive + Node built-ins only — no npm dependency introduced, so no legitimacy gate applies |
