## The RCP-09 enumeration, ruled

RCP-09 names: the production and debug Assigned Access XML, three package sources, two
detect/remediate pairs, the triage sensor and two diagnostics. D-28 requires the 10-versus-12
ambiguity to be ruled explicitly rather than left to the executor.

**Ruling: a detect/remediate pair is two files, so the enumeration is 10 items and 12 payload files.**
Intune Remediations takes a detection script and a remediation script as two separate uploads; a
"pair" that were one file would not be deployable. RE-237`:193` describes publishing "the same two
scripts as detect/remediate pairs, plus a detection-only triage sensor", which is two pairs and a
sensor, five files, plus the two diagnostics, the two XML files and the three package sources.
