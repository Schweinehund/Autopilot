# Anthropomorphism

_Source: https://developers.google.com/style/anthropomorphism_

Don't attribute human qualities to software or hardware.

Anthropomorphism is a category of figurative language, which is less precise and is often harder to understand and translate than direct language. For more information, see [Write for a global audience](translation.md).

: A Delimiter object tells the splitter where a string should be broken.

: The PC detects a new device.

: The PC sees a new device.
